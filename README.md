# TongLi98.github.io

这是 TongLi98 的个人网站，使用原生 HTML、CSS 和 JavaScript 构建，可以直接部署到 GitHub Pages。

## 文件结构

- `index.html`：页面内容和结构
- `styles.css`：响应式视觉样式
- `script.js`：页脚年份和滚动出现动画

## 本地预览

直接在浏览器打开 `index.html` 即可预览。

## 发布

仓库远端已指向：

```text
https://github.com/TongLi98/TongLi98.github.io.git
```

推送到 `main` 分支后，GitHub Pages 通常会发布到：

```text
https://tongli98.github.io/
```

后续可以继续替换真实邮箱、LinkedIn、项目链接、个人简介和头像。
