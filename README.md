# 个人网站

这是一个可以直接部署到 GitHub Pages 的静态个人网站模板。

## 本地文件

- `index.html`：页面结构
- `styles.css`：视觉样式
- `script.js`：滚动出现动画和页脚年份

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，名字设为 `TongLi98.github.io`。
2. 把这几个文件上传到仓库根目录。
3. 进入仓库的 `Settings` -> `Pages`。
4. 在 `Build and deployment` 里选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`。
6. 保存后，等待 GitHub Pages 发布完成。

你的站点发布后，地址会直接是 `https://tongli98.github.io/`。

## 下一步可改内容

- 把首页名字、简介、项目、联系方式替换成你的真实信息
- 如果你愿意，可以继续加博客、作品集、简历下载和深色模式
